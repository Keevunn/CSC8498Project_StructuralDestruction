# ControlledDemolition

CSC8498: Design and Evaluation of Graph-Based Structural Approximations for Real-Time Game Destruction
Developed with Unreal Engine 5

The project can be run from '\Windows\ControlledDemolition.exe'

---------------------------------------

Controls:

Player movement:
Walk - WASD
Jump - Space

Restart level - R

Debug:
Toggle draw debug - Right Alt
Toggle verbose log - Right Ctrl

---------------------------------------

Piece Colour Guide:
Anchor - Magenta
Support - Yellow
Load - White
Objective - Green
Protected - Cyan

---------------------------------------

After running benchmark sweeps, data is saved in '\Windows\ControlledDemolition\Saved\BenchmarkResults\DemolitionBenchmark.csv'
